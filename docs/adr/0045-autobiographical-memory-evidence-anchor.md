# ADR-0045 — Resolved autobiographical memory requires canonical evidence anchoring

- **Status:** Accepted
- **Date:** 2026-09-05

## Context

Kaira's selective self-memory runtime already supplies canonical autobiographical records to the realizer and explicitly instructs it not to invent people, places, times, causes or details that are absent from those records. The unified final constraint pass also runs the autobiographical response guard.

A measured integrity gap remained: when an autobiographical memory was successfully resolved, the final guard treated the existence of any memory evidence as sufficient and returned the generated reply unchanged. A wholly unrelated model-prior story could therefore replace the resolved canonical memory even though the prompt contained the correct record.

The repository also contains canonical conversational Claim provenance, but that contract represents who asserted what about whom in dialogue. It is not a typed extractor for claims generated by the model. Reusing it as though it parsed generated autobiographical prose would create a new semantic authority and is therefore rejected.

## Decision

For a resolved `autobiographical_memory` query with at least one canonical memory:

- The final reply must carry at least one lexical/morphological evidence anchor from the strongest ranked canonical memory.
- Evidence anchors are derived only from already-canonical memory fields: `eventType`, `facts`, emotion labels, `placeId` and `participantIds`.
- The guard does not re-parse the user message and does not infer new memory facts.
- Natural realization is preserved when it contains a canonical anchor, including common Turkish inflection variants handled by bounded prefix comparison.
- If the reply contains no canonical anchor at all, it is treated as wholesale memory substitution and replaced with a deterministic summary of the canonical memory facts.

This is deliberately **not** a general generated-claim verifier. A reply that contains a true canonical anchor plus an unsupported extra detail is outside this decision and must be addressed only after a separate measured regression and an appropriate typed evidence design.

## Consequences

- A completely unrelated invented autobiography can no longer replace a resolved canonical memory at final delivery.
- Natural grounded paraphrases remain available; resolved autobiography is not converted into an always-deterministic renderer.
- Claim provenance, RelationshipReducer, world memory, ResponsePlan and semantic interpretation remain unchanged.
- The scope is intentionally narrower than full sentence-level factual entailment, avoiding a new regex-based semantic brain.

## Regression coverage

- `src/services/kairaAutobiographicalResponseGuardContracts.test.ts` covers grounded paraphrase preservation and zero-anchor replacement.
- `src/services/kairaAutobiographicalEvidenceAnchorRegression.test.ts` permanently falsifies the wholesale invented-memory counterexample and preserves a natural anchored realization.

## Revisit condition

Revisit only when a measured live or deterministic regression demonstrates that a reply can preserve a canonical anchor while materially inventing an unsupported autobiographical person, place, time, cause or event detail. Such a change should prefer a typed generated-claim/evidence contract over expanding lexical heuristics.
